# Schibsted Grotesk

Unmodified TrueType weights 400, 500, 600, 700, and 800 are bundled for offline
rendering and consistent typography. Their weight mappings are in `pubspec.yaml`.

Source: [Google Fonts](https://fonts.google.com/specimen/Schibsted+Grotesk),
downloaded from its stylesheet endpoint on 2026-10-08:

`https://fonts.googleapis.com/css2?family=Schibsted+Grotesk:wght@400;500;600;700;800&display=swap`
